Concepto
¿Qué es Liquid Glass?
El nuevo sistema de diseño de Apple para iOS 26 / iPhone 17. Superficies de vidrio translúcido que reaccionan al contenido del fondo — blur, refracción, bordes luminosos y profundidad en capas.
🔮

Translucidez

El fondo se filtra a través del elemento. Blur intenso que crea sensación de profundidad real.

✨

Especular

Bordes con gradiente luminoso que simulan luz rebotando en el vidrio. Efecto top-highlight.

🌊

Adaptativo

El elemento cambia su opacidad según el contenido debajo. Más blur = más legibilidad.

Variables CSS
Design Tokens
Pegá estas variables en el :root de tu CSS. Son la base de todo el sistema.
/* === iOS 26 Liquid Glass — Dark Mode Tokens === */ :root { /* Fondo base */ --bg-deep: #050508; --bg-surface: #0c0c14; /* Glass — superficies */ --glass-bg: rgba(255,255,255,0.06); --glass-bg-hover: rgba(255,255,255,0.10); --glass-border: rgba(255,255,255,0.14); --glass-border-strong: rgba(255,255,255,0.24); /* Blur */ --glass-blur: blur(24px) saturate(180%); --glass-blur-heavy: blur(40px) saturate(200%); /* Texto */ --text-primary: rgba(255,255,255,0.95); --text-secondary: rgba(255,255,255,0.60); --text-tertiary: rgba(255,255,255,0.35); /* Acentos (Apple system colors) */ --accent-blue: #0a84ff; --accent-teal: #30d158; --accent-purple: #bf5af2; --accent-orange: #ff9f0a; --accent-red: #ff453a; --accent-cyan: #5ac8fa; /* Radios */ --radius-sm: 12px; --radius-md: 16px; --radius-lg: 22px; --radius-xl: 30px; --radius-full: 999px; /* Sombras */ --shadow-glass: 0 8px 32px rgba(0,0,0,0.4), 0 2px 8px rgba(0,0,0,0.3), inset 0 1px 0 rgba(255,255,255,0.12); } /* === Clase base glass === */ .glass { background: var(--glass-bg); backdrop-filter: var(--glass-blur); -webkit-backdrop-filter: var(--glass-blur); border: 1px solid var(--glass-border); box-shadow: var(--shadow-glass); border-radius: var(--radius-lg); } /* Top-highlight (especular del vidrio) */ .glass::before { content: ''; position: absolute; top: 0; left: 0; right: 0; height: 1px; background: linear-gradient(90deg, transparent, rgba(255,255,255,0.3), transparent); }

Instrucciones
Prompt para tu IA coder
Copiá esto y pegalo como instrucciones de diseño en Cursor, v0, Bolt o el agente que uses. Reemplazá las secciones entre corchetes con el contenido de tu página.
SISTEMA DE DISEÑO: iOS 26 Liquid Glass — Dark Mode

Diseñá esta página siguiendo exactamente el sistema visual de iOS 26 Liquid Glass en modo oscuro. Referencia directa: iPhone 17 / iOS 26 / Apple Liquid Glass.
FONDO:
— Color base: #050508 (casi negro, con tinte azul muy leve)
— Agregar 2-3 orbes de color difuso en el fondo (posición fija, pointer-events: none) con filter: blur(80-120px) y opacity: 0.35-0.45. Colores sugeridos: azul (#0a84ff), violeta (#bf5af2), verde (#30d158).
— Los orbes deben tener animación CSS suave de drift (transform translate) con duración 15-25s y ease-in-out infinite.
SUPERFICIES GLASS (usar en cards, navs, modales, inputs):
— background: rgba(255,255,255,0.06)
— backdrop-filter: blur(24px) saturate(180%)
— border: 1px solid rgba(255,255,255,0.14)
— box-shadow: 0 8px 32px rgba(0,0,0,0.4), inset 0 1px 0 rgba(255,255,255,0.12)
— border-radius: mínimo 16px. Cards grandes: 22-30px. Botones: 999px (pill).
TOP HIGHLIGHT (obligatorio en cards y modales):
Agregar ::before con position absolute, height: 1px, background: linear-gradient(90deg, transparent, rgba(255,255,255,0.3), transparent). Simula la luz que rebota en el borde superior del vidrio.
TEXTOS:
— Primario: rgba(255,255,255,0.95)
— Secundario: rgba(255,255,255,0.60)
— Terciario: rgba(255,255,255,0.35)
— Títulos hero: font-weight 300, letter-spacing -0.03em a -0.04em
— Títulos sección: font-weight 500, letter-spacing -0.02em
— Fuente: -apple-system, BlinkMacSystemFont, 'Inter', sans-serif
BOTÓN PRIMARIO:
background: #0a84ff, color: white, border-radius: 999px, box-shadow: 0 0 20px rgba(10,132,255,0.4). Hover: brighten + translateY(-1px).
NAVBAR:
Posición sticky top. Glass completo. Links activos con glass interno. CTA con accent azul. Padding generoso. border-radius: 999px o 22px si es full-width.
INPUTS:
background: rgba(255,255,255,0.05), backdrop-filter: blur(16px), border: rgba(255,255,255,0.14). Focus ring: 0 0 0 3px rgba(10,132,255,0.2). Placeholder: rgba(255,255,255,0.35).
COLORES DE ACENTO (Apple dark system colors):
Blue: #0a84ff | Green: #30d158 | Purple: #bf5af2 | Orange: #ff9f0a | Red: #ff453a | Cyan: #5ac8fa
REGLAS CRÍTICAS:
— NUNCA usar blancos/negros sólidos en fondos. Todo debe ser semi-transparente.
— TODO elemento interactivo debe tener backdrop-filter.
— backdrop-filter requiere position: relative en el padre y overflow: hidden en algunos casos.
— Agregar transiciones suaves (0.2s ease) en hover de todos los elementos glass.
— Sin sombras de texto (text-shadow) salvo en casos extremos de contraste.
— La jerarquía visual se logra variando la opacidad del bg glass (0.04 / 0.06 / 0.10 / 0.15).
